# Customer Segmentation & Review Intelligence

An intelligent customer analytics system that identifies different customer groups based on their purchasing behaviour and product reviews. The project combines machine learning and natural language processing to discover customer patterns, evaluate customer segments, and generate actionable business recommendations.

## 1. Project Overview

Understanding customer behaviour is important for businesses to improve customer experience and build stronger customer relationships.

This project uses K-Means clustering to group customers based on purchasing patterns, ratings, and review-related features. It applies NLP techniques to extract useful information from customer reviews and uses XGBoost to classify customers into their identified segments.

The system also assigns business personas to customer groups and suggests suitable marketing and customer-retention strategies.

## 2. Project Objectives

- Identify meaningful customer segments using purchasing behaviour.
- Analyse customer reviews using Natural Language Processing.
- Evaluate clustering performance using Silhouette Score and Davies-Bouldin Index.
- Visualize customer segments using PCA.
- Apply XGBoost to classify customers into identified segments.
- Generate customer personas and actionable business recommendations.

## 4. Project Workflow

**Step 1: Data Loading and Preprocessing**

Customer purchasing information and review data are loaded and prepared for analysis. The current implementation generates a synthetic customer and review dataset.

**Step 2: Review Analysis using NLP**

TF-IDF converts review text into numerical features, while Truncated SVD reduces the dimensionality of the text features.

**Step 3: Feature Scaling**

StandardScaler brings numerical features to comparable scales before clustering.

**Step 4: Customer Segmentation using K-Means**

K-Means groups customers based on their purchasing behaviour and review-related features.

**Step 5: Clustering Evaluation**

Different cluster counts are evaluated using:
- Silhouette Score
- Davies-Bouldin Index

The cluster configuration with the highest Silhouette Score is selected from the eligible candidates.

**Step 6: PCA Visualization**

PCA is used to visualize customer segments and their centroids in a two-dimensional representation.

**Step 7: XGBoost Classification**

XGBoost is trained to classify customers using the segment labels generated by K-Means. Five-fold stratified cross-validation and a separate test set are used for evaluation.

**Step 8: Business Personas and Recommendations**

Customer groups are assigned business personas, along with recommended actions to improve engagement and retention.

## 5. Customer Personas

The system identifies the following business personas:

| Customer Segment | Recommended Business Action |
|---|---|
| Champions & Brand Advocates | VIP loyalty programs, referrals and early product access |
| At-Risk Dissatisfied Reviewers | Priority support and service recovery offers |
| Dormant / Lapsed Buyers | Targeted win-back campaigns and personalized offers |
| Core Steady Customers | Product bundles and cross-selling |

Multiple K-Means clusters can map to the same business persona based on their characteristics.

## 8. How to Run the Project

**Prerequisites:**
- Python installed
- Git installed
- VS Code or another Python development environment

**Step 1: Clone the repository**

```bash
git clone https://github.com/lakshmi-prasanna-techie/Customer-Segmentation-Review-Intelligence.git
```

**Step 2: Navigate into the project**

```bash
cd Customer-Segmentation-Review-Intelligence
```

**Step 3: Install dependencies**

```bash
pip install -r customer_segmentation/requirements.txt
```

**Step 4: Run the project**

```bash
python customer_segmentation/main.py
```

The pipeline generates the customer segments, evaluates the models, creates visualizations, and saves the output artifacts inside the artifacts directory.

## 9. Output Artifacts

The project saves the following outputs:

- **segmentation_bundle.joblib:** Stores the trained models, scaler, PCA object and related feature-processing components.
- **segmented_customers.csv:** Contains customer records with their assigned segments, personas and recommended actions.
- **pipeline_metrics.json:** Stores clustering and classification evaluation metrics.
